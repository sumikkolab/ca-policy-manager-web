[Application-Specific Provisions]

Article 7 (About the Application)

7.1 The Application is a Windows application that reads Conditional Access policies and sign-in logs from Microsoft Entra ID and shows how those policies apply. It is intended for administrators who manage their own organization's tenant.

7.2 The Application is read-only. It does not modify policies, settings or users. Where a change is needed, the Application only produces a proposal as text; you review and apply it yourself.

Article 8 (Information Retrieved and Permissions)

8.1 You sign in with your work or school account, and the Application reads the following from Microsoft Graph within your permissions:
(a) sign-in logs (including time, result, applied policies, IP address and location, and user and application names);
(b) Conditional Access policy definitions and named locations;
(c) users' group membership;
(d) application display names, used solely to show names on screen. This is optional; without it, all other features remain available; and
(e) user and group display names, and groups' members and parent groups, used solely to search for and check emergency access accounts and to show groups in the policy check. They are kept in this PC's memory only and are not saved. The permission to read group information (names, members, and parent groups) is optional; without it, all other features remain available.

8.2 All permissions requested are read-only.

Article 9 (Data Storage)

9.1 Retrieved information is stored only on this PC, in the current Windows user's folder.

9.2 Sign-in records are stored unencrypted and contain full IP addresses (user names are hashed). There is no retention limit and nothing is deleted automatically; apart from being replaced when the same period is retrieved again, the records remain until you delete them.

9.3 User names and group membership, policy definitions, and connection settings (such as the tenant ID) are stored encrypted.

9.4 Access tokens are kept in memory only and are never written to a file.

Article 10 (Data Transmission)

10.1 The Application itself communicates only with Microsoft sign-in and Microsoft Graph (read-only).

10.2 The Application does not send retrieved information, usage data or error information to the Publisher or to any third party.

10.3 Operating-system mechanisms such as Windows Error Reporting are governed by your OS settings.
