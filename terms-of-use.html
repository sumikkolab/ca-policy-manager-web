4. 取得、保存、送信する情報については、後記の「本アプリ固有の事項」によります。

【本アプリ固有の事項】

第 7 条(本アプリについて)

1. 本アプリは、Microsoft Entra ID の条件付きアクセスのポリシーとサインインログを読み取り、その適用状況を確認する Windows 用アプリで、自分の組織のテナントを管理する管理者を対象とします。

2. 本アプリは読み取り専用で、ポリシー、設定、ユーザーを変更しません。変更案はテキストでエクスポートするにとどまり、適用は利用者が行います。

第 8 条(取得する情報とアクセス許可)

職場または学校のアカウントでサインインし、そのアクセス許可の範囲で Microsoft Graph から次の情報を読み取ります。アクセス許可はすべて読み取り専用です。
(1) サインインログ(日時、結果、適用ポリシー、IP アドレスと場所、ユーザーとアプリの名前など)
(2) 条件付きアクセスのポリシー定義とネームドロケーション
(3) ユーザーのグループ所属
(4) アプリの表示名(画面の表示のみ。任意で、無くても他の機能は利用できます)
(5) ユーザーとグループの表示名、グループのメンバーと上位のグループ(緊急アクセス アカウントの検索と確認、ポリシーの点検でのグループの表示のみ。この PC のメモリにだけ保持し、保存しません。グループの名前・メンバー・上位のグループを読み取るアクセス許可は任意で、無くても他の機能は利用できます)

第 9 条(データの保存)

1. 取得した情報は、この PC の現在の Windows ユーザーのフォルダーにのみ保存します。

2. サインインの記録は暗号化せずに保存し、IP アドレスを完全な形で含みます(ユーザー名はハッシュ化します)。保持の期限はなく、自動では削除されません。同じ期間を再取得したときに置き換わるほかは、利用者が削除するまで残ります。

3. ユーザーの名前と所属、ポリシー定義、接続設定(テナント ID など)は、暗号化して保存します。

4. アクセストークンはファイルに保存せず、メモリ上にのみ保持します。

第 10 条(外部への送信)

1. 本アプリ自身の通信は、Microsoft のサインインと Microsoft Graph の読み取りに限られます。

2. 取得した情報、利用状況、エラーの情報を、発行元または第三者に送信しません。

3. Windows のエラー報告など OS の仕組みによる送信は、OS の設定に従います。

第 11 条(分析結果の性質)

1. 分析結果は本アプリの計算による推定であり、Microsoft の公式の評価ではなく、実際の判定と異なることがあります。

2. 判定に対応していない条件や取得できなかった情報は、「結果を確定できない」または「データ不足」として扱います。

3. ポリシーを変更する前に、必ず検証用の環境またはレポート専用モードで確認してください。

4. 設定に緊急アクセスの ID があると、変更案にその ID が含まれます。

第 12 条(データの削除)

設定の「保存したデータを削除」で、サインインログ、ユーザーの名前と所属、ポリシー定義を削除できます。同意するまで、取得も保存もしません。
