製品情報マニュアルプライバシーポリシー利用規約サポート

始め方

インストールから最初の取得まで

動作環境

  • OS: Windows 10 バージョン 2004 以降、Windows 11
  • ネットワーク: Microsoft のサインインと Microsoft Graph への接続
  • ライセンス: Microsoft Entra ID P1 または P2
  • アカウント: 職場または学校のアカウント。ロールは Global Reader を推奨します(必要な条件)。

手順

  1. Microsoft Store からインストールします。
  2. アプリを起動し、利用規約と免責事項を確認します。「同意しない(終了)」を選択すると、アプリは終了します。同意するまで、取得も保存もしません。
  3. Microsoft Entra 管理センターでアプリを登録します。
  4. 歯車のアイコンから設定を開き、「接続設定」でテナント ID とクライアント ID を入力します。
  5. 上部の「期間」を選択し、「取得」を選択します。Windows のサインインのダイアログが表示されたら、サインインします。

取得の期間

  • 期間は 24 時間、7 日、30 日、または指定期間(最大 30 日)から選択します。
  • 「前回以降の情報のみ取得」を選択すると、前回の取得以降の情報だけを取得します。
  • 取得するサインインは対話型のサインインだけです。
  • ログの保持期間はライセンスによって異なります。実際に取得できた範囲は画面に表示します。

有償版の購入

CAシミュレーション、レポート専用ポリシーの評価、変更案の作成、CSV・HTML のエクスポートは有償版で利用できます。有償版は Microsoft Store の買い切りのアドオンで、アプリの「有償版を購入」から購入します。購入状況を確認できないときは、有償機能を利用できません。
